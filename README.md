## FlowHQ Outreach

[`flowhq-outreach/`](flowhq-outreach/README.md) is an evidence-based, personalised B2B outreach system for FlowHQ, built from n8n workflows, Google Sheets and Gmail. It is self-contained and separate from any other automation.

Start with [flowhq-outreach/README.md](flowhq-outreach/README.md), then [docs/SETUP.md](flowhq-outreach/docs/SETUP.md).
